# GorkyCode Assistant

Голосовой помощник для управления задачами, напоминаниями и встречами.

## Возможности

- Создание задач и напоминаний с помощью текста.
- Голосовой ввод и распознавание речи.
- Определение содержания задачи, даты и времени с помощью ИИ.
- Просмотр и управление запланированными делами.
- Локальное хранение данных пользователя.

## Технологии

- Python
- Streamlit
- SQLite
- Supabase Edge Functions
- Groq API

## Установка и запуск на Windows

### 1. Установите Python

Скачайте и установите Python с официального сайта:

https://www.python.org/downloads/

При установке отметьте пункт **Add Python to PATH**.

### 2. Скачайте проект

Откройте терминал и выполните:

```powershell
git clone https://github.com/peethpath/gorkycode-assistant.git
```

Перейдите в папку проекта:

```powershell
cd gorkycode-assistant
```

### 3. Создайте виртуальное окружение

```powershell
py -m venv .venv
```

Активируйте его:

```powershell
.venv\Scripts\activate
```

### 4. Установите зависимости

```powershell
py -m pip install -r requirements.txt
```

### 5. Настройте подключение к ИИ

Создайте файл `.env` в корневой папке проекта.

Добавьте в него параметры подключения:

```env
SUPABASE_URL=адрес_проекта_supabase
SUPABASE_KEY=публичный_publishable_ключ
```

Для работы ИИ используется серверная функция Supabase. Собственный API-ключ Groq пользователю не требуется.

### 6. Запустите приложение

```powershell
py -m streamlit run app.py
```

После запуска приложение откроется в браузере.

## Хранение данных

Задачи и напоминания сохраняются локально в базе данных SQLite (`assistant.db`) на компьютере пользователя.

## Безопасность

Файл `.env` содержит настройки подключения и не должен публиковаться в репозитории.
