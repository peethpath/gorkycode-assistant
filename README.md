# GorkyCode Assistant

Голосовой помощник для управления повседневными задачами, напоминаниями и встречами с помощью текста и голоса.

Проект позволяет быстро создавать задачи на естественном языке, автоматически определять дату и время выполнения и хранить запланированные дела в одном месте.

## Возможности

- **Создание задач текстом.** Пользователь может описать задачу обычным сообщением.
- **Голосовой ввод.** Создание задач с помощью голоса без необходимости самостоятельно набирать текст.
- **Распознавание речи.** Преобразование голосовых сообщений в текст.
- **Обработка запросов с помощью ИИ.** Определение содержания задачи, даты и времени из естественной речи.
- **Управление задачами.** Просмотр запланированных дел, удаление задач и отметка выполненных.
- **Локальное хранение.** Сохранение задач на компьютере пользователя.

## Используемые технологии

| Технология | Назначение |
|---|---|
| Python | Основной язык программирования |
| Streamlit | Создание пользовательского интерфейса |
| SQLite | Локальное хранение задач и напоминаний |
| Supabase Edge Functions | Серверная обработка запросов к ИИ |
| Groq API | Обработка текстовых запросов и распознавание речи |

## Структура проекта

```text
gorkycode-assistant/
│
├── app.py              # Основной файл приложения
├── requirements.txt    # Список необходимых библиотек
├── .env.example        # Пример настроек подключения
```

Файл `assistant.db` создаётся локально при работе приложения и содержит задачи пользователя.

## Установка и запуск

Инструкция предназначена для пользователей Windows.

### 1. Скачивание проекта

Откройте репозиторий проекта:

https://github.com/peethpath/gorkycode-assistant

Нажмите кнопку **Code → Download ZIP**.

Скачайте архив и распакуйте его в удобную папку на компьютере.

### 2. Установка Python

Если Python ещё не установлен, скачайте его с официального сайта:

https://www.python.org/downloads/

При установке Windows рекомендуется отметить пункт **Add Python to PATH**.

Проверить установку можно командой:

```powershell
py --version
```

### 3. Открытие папки проекта

Откройте терминал PowerShell в распакованной папке `gorkycode-assistant`.

Убедитесь, что в текущей папке находятся файлы `app.py` и `requirements.txt`.

### 4. Создание виртуального окружения

Выполните команду:

```powershell
py -m venv .venv
```

Активируйте виртуальное окружение:

```powershell
.venv\Scripts\activate
```

### 5. Установка зависимостей

Установите необходимые библиотеки:

```powershell
py -m pip install -r requirements.txt
```

### 6. Настройка подключения к ИИ

В корневой папке проекта находится файл `.env.example` с параметрами подключения к Supabase.

Создайте рабочий файл `.env` на его основе:

```powershell
Copy-Item .env.example .env
```

Файл `.env` должен находиться в одной папке с `app.py`.

В нём должны быть указаны следующие параметры:

```env
SUPABASE_URL=адрес_проекта_supabase
SUPABASE_KEY=публичный_publishable_ключ
```

Если значения уже указаны в `.env.example`, дополнительно вводить их не требуется.

Собственный API-ключ Groq для запуска приложения не нужен. Обработка запросов искусственным интеллектом и распознавание речи выполняются через серверную функцию Supabase.

### 7. Запуск приложения

После установки зависимостей и настройки подключения выполните:

```powershell
py -m streamlit run app.py
```

После запуска приложение откроется в браузере по локальному адресу, который отобразится в терминале.

Чтобы остановить приложение, нажмите `Ctrl + C` в терминале.

## Хранение данных

Для хранения задач и напоминаний используется SQLite.

База данных `assistant.db` создаётся на компьютере пользователя. Задачи сохраняются локально, поэтому у каждого пользователя своя база данных.

## Архитектура работы

1. Пользователь вводит запрос текстом или голосом.
2. При голосовом вводе аудиозапись отправляется на серверную функцию Supabase для распознавания речи.
3. Текстовый запрос передаётся через серверную функцию в Groq API.
4. Искусственный интеллект анализирует запрос и определяет содержание задачи, дату и время.
5. Приложение обрабатывает полученные данные и сохраняет задачу в локальной базе SQLite.
6. Пользователь может просматривать и управлять своими задачами через интерфейс приложения.

## Безопасность

- Локальная база данных `assistant.db` не публикуется в репозитории.
- Рабочий файл `.env` не загружается в GitHub.
- Для обращения к ИИ используется серверная функция Supabase.
- API-ключ Groq хранится в настройках Supabase, а не в исходном коде приложения.
- В публичном репозитории используется Supabase Publishable Key.

**Важно:** Publishable Key предназначен для публичного использования и сам по себе не ограничивает доступ к серверной функции. Поскольку проект публичный, посторонние пользователи могут попытаться обращаться к AI-прокси. Необходимо контролировать расход API и использовать серверные ограничения запросов.

## Возможные проблемы

**Команда `py` не распознана.**

Проверьте установку Python и наличие Python в системной переменной PATH.

**Команда `streamlit` не распознана.**

Используйте запуск через Python:

```powershell
py -m streamlit run app.py
```

**Ошибка подключения к Supabase.**

Проверьте наличие файла `.env`, правильность адреса проекта и Publishable Key.

**Не устанавливаются библиотеки.**

Убедитесь, что виртуальное окружение активировано, и повторите установку:

```powershell
py -m pip install -r requirements.txt
```
